# LoL

Esqueleto inicial para replicar el pipeline de value betting en League of Legends.

Piezas previstas:

- ETL historico de partidas y estadisticas por equipo/jugador.
- Entrenamiento de modelos por mercado.
- Inferencia diaria sobre encuentros proximos.
- Listener de odds con delta logging y deteccion de EV.

Pendiente definir:

- proveedor de datos historicos,
- proveedor de cuotas,
- mercados objetivo,
- esquema de mapping entre equipos y eventos.
